# J_best.dat

## 文件作用
在 `Model atomic_effective_H` 中提供相互作用参数的实际取值。

## 何时需要
当已完成相互作用分析，并准备进行 MC 等模拟、需要显式指定所采用的参数集合时使用。

## 关键字段/内容
文件按严格逐行规则读取。

### 第 1 行：两个数据
1. 总相互作用数
2. 模拟中保留的参数个数（不含常数项）

### 后续每组信息
- 参数编号
- 参数取值

其中参数编号需与以下输出文件中的编号一致：
- `all_interaction_type_Spin_xyzform.dat`
- `local_mode_PM.dat`

## 注意事项
- 不能任意插入空行
- `#` 后可写注释，但 `#` 需与数据用空格或制表符隔开
- 自旋向量默认已归一化，因此相互作用参数单位与能量一致，取 eV
