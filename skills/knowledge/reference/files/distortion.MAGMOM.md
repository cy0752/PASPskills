# distortion.MAGMOM

## 文件作用
为自定义构型提供超胞中每个原子的磁矩向量。

## 何时需要
仅当自定义构型中涉及自旋模式时需要；与 `distortion.pos` 搭配使用。

## 关键字段/内容
- 每行对应一个原子
- 每行 3 个数：磁矩的 `x y z` 分量
- 行顺序必须与 `distortion.pos` 的原子顺序一致
- 非磁性原子写 `0 0 0`

## 注意事项
- 对于非零自旋模式，向量模长不重要，PASP 内部会做归一化
- 真正关键的是方向和与 `distortion.pos` 的原子顺序一致性

## 最小示例
```text
0 0 0
-1.9464 -2.8302 2.0498
2.6410 2.0453 -2.2005
0 0 0
```
