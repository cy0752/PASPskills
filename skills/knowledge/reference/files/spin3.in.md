# spin3.in

## 文件作用
提供初始自旋构型或参考自旋构型。

## 何时需要
适用于以下模型或场景：
- `Model Spin_lattice_interaction` 中，`Read_init_spin = T`
- `Model KNB` 中指定自旋构型
- `Model find_J_path_sym` 中指定参考构型，用于四态法构造若干第一性原理计算

## 关键字段/内容
每行格式：
1. 原子编号
2. 自旋 `Sx`
3. 自旋 `Sy`
4. 自旋 `Sz`

要求：
- 磁性原子给归一化自旋矢量
- 非磁性原子给零向量 `0 0 0`

## 注意事项
- 原子顺序必须与超胞中原子编号顺序一致
- 如果超胞是通过 `block SuperCell` 从 `cell.str` 扩出来的，原子顺序往往不易预判
- 因此通常建议直接在 `cell.str` 中写超胞结构，让 `spin3.in` 的顺序直接与 `cell.str` 一致

## 最小示例
```text
1 -0.54157046 -0.56570479 -0.62183562
2 -0.54499053 -0.56493211 -0.61954582
5 0.00000000 0.00000000 0.00000000
```
