# block BandLines

## 含义
能带计算设置，第一列表示路径上取点数目，第二列至第三列分别表示所选高对称点的分数坐标，最后一列为高对称点符号。使用时在block之前应添加“ BandLinesScale ”输入来设置高对称点表示方法。

## 默认值
无

## 取值
见描述

## 何时使用
- 当使用 `3.1.9 紧束缚模型方法常用设置项` 相关功能并需要设置 `block BandLines` 时。

## 注意事项
- 这是 block 类型设置，写入时必须使用 `%block ... %endblock` 结构，并保持 block 内格式完整。
- 若涉及精确行格式或复杂示例，应回到来源章节核对。
