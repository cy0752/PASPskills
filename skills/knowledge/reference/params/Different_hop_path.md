# Different_hop_path

## 含义
在自定义TB中，每对发生跃迁的元素为一条hop_path；在S-K TB中，每对跃迁壳层组合为一条hop_path。

## 默认值
在S-K TB中为1，自定义TB中手动输入hopping参数时为0

## 取值
非负整数

## 何时使用
- 当使用 `3.1.9 紧束缚模型方法常用设置项` 相关功能并需要设置 `Different_hop_path` 时。

## 注意事项
- 修改前应确认当前 workflow 阶段确实需要该设置，不要用参数调整掩盖结构或文件依赖错误。
- 若涉及精确行格式或复杂示例，应回到来源章节核对。
