# GA.Pher

## 含义
用于设置遗传算法交叉的概率。

## 默认值
0.85

## 取值
0~1之间的实数

## 相关逻辑
- `GA.Pher` 和 `GA.Pmut` 会共同决定遗传操作数量；当前源码逻辑中 `Pperm = 1.0 - GA.Pher - GA.Pmut`，并据此计算剩余操作数量。
- 如果 `GA.Pher + GA.Pmut < 1`，剩余比例会进入 `Pperm` 对应的操作路径；如果这不是用户有意设置，workflow 应提示用户确认。
- 如果 `GA.Pher + GA.Pmut > 1`，`Pperm` 会变成负数，属于高风险设置，应在输入 preflight 中阻断或要求用户更正。

## 何时使用
- 当使用 `3.1.8 全局结构搜索常用设置项` 相关功能并需要设置 `GA.Pher` 时。

## 注意事项
- 修改前应确认当前 workflow 阶段确实需要该设置，不要用参数调整掩盖结构或文件依赖错误。
- L6 workflow 中常见的稳妥做法是让 `GA.Pher + GA.Pmut = 1`，例如 `0.75/0.25` 或 `0.80/0.20`，但这属于 workflow 设置建议，不是源码默认值。
- 若涉及精确行格式或复杂示例，应回到来源章节核对。
