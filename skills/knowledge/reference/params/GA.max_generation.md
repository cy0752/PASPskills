# GA.max_generation

## 含义
用于设置遗传算法的迭代次数。

## 默认值
0

## 取值
非负整数

## 何时使用
- 当使用 `3.1.8 全局结构搜索常用设置项` 相关功能并需要设置 `GA.max_generation` 时。

## 注意事项
- 修改前应确认当前 workflow 阶段确实需要该设置，不要用参数调整掩盖结构或文件依赖错误。
- 当前 reference/source 记录的默认读取值为 `0`。正式 GA 搜索不应依赖该默认值，应由用户按体系规模、搜索类型和计算预算显式确认。
- 很小的设置只适合 smoke test。像 `GA.max_generation 2` 这类设置不能自动视为生产搜索；workflow 应要求标注 smoke-test 或 production。
- 该参数不会自动随体系大小调整。微扰搜索通常搜索空间更小，全局搜索通常需要更谨慎地确认代数。
- 若涉及精确行格式或复杂示例，应回到来源章节核对。
