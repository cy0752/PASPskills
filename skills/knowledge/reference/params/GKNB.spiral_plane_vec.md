# block GKNB.spiral_plane_vec

## 含义
采用笛卡尔坐标形式，提供相互正交的两个单位方向向量，分别记为 \(e_1\) 和 \(e_2\) 。

## 默认值
需要用到时不可缺省

## 取值
两行分别为相互正交的两个单位方向向量

## 何时使用
- 当使用 `3.1.10 自旋序诱导铁电性统一极化模型常用设置项` 相关功能并需要设置 `block GKNB.spiral_plane_vec` 时。

## 注意事项
- 这是 block 类型设置，写入时必须使用 `%block ... %endblock` 结构，并保持 block 内格式完整。
- 若涉及精确行格式或复杂示例，应回到来源章节核对。
