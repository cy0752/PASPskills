# Hop_Parameters_specified_using_dis

## 含义
选用T则以原子间距离表示跃迁路径，若该项选用F，则 Hop_Parameters_specified_using_site 一项必须为T。

## 默认值
F

## 取值
T/F

## 何时使用
- 当使用 `3.1.9 紧束缚模型方法常用设置项` 相关功能并需要设置 `Hop_Parameters_specified_using_dis` 时。

## 注意事项
- 修改前应确认当前 workflow 阶段确实需要该设置，不要用参数调整掩盖结构或文件依赖错误。
- 若涉及精确行格式或复杂示例，应回到来源章节核对。
