# Invariant.cal_para

## 含义
在有效哈密顿量方法模块中常用。用于设置在分析完各种不等价相互作用项之后，是否计算若干构型的 \(\left\{h_{j}^{(i)}\right\}\) （定义见2.2.1节）并输出到 *.ene_symbol 文件中。这些构型可以是随机生成的，也可以是自定义的，这由“ local_mode.cal_para_method ”设置项决定。

## 默认值
F

## 取值
T/F

## 何时使用
- 当使用 `3.1.7.7 随机生成构型或自定义构型的相关设置` 相关功能并需要设置 `Invariant.cal_para` 时。

- 修改前应确认当前 workflow 阶段确实需要该设置，不要用参数调整掩盖结构或文件依赖错误。
