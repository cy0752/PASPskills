# Invariant.type

## 含义
用于选定“Model Invariant”中分析不等价相互作用时的具体方法。本手册仅涉及选项2，即分析自定义的局域模式之间的不等价相互作用。其他选项不常用，这里不展开介绍。

## 默认值
1

## 取值
1/2/3/5/6

## 何时使用
- 当使用 `3.1.7.9 Model Invariant 的其他设置` 相关功能并需要设置 `Invariant.type` 时。

## 注意事项
- 修改前应确认当前 workflow 阶段确实需要该设置，不要用参数调整掩盖结构或文件依赖错误。
- 若涉及精确行格式或复杂示例，应回到来源章节核对。
