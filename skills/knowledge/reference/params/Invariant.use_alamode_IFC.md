# Invariant.use_alamode_IFC

## 含义
在有效哈密顿量方法模块中可能用到（目前不常用）。用于设置是否采用全原子模型。

## 默认值
F

## 取值
T/F

## 何时使用
- 当使用 `3.1.7.7 随机生成构型或自定义构型的相关设置` 相关功能并需要设置 `Invariant.use_alamode_IFC` 时。

## 注意事项
- 修改前应确认当前 workflow 阶段确实需要该设置，不要用参数调整掩盖结构或文件依赖错误。
- 若涉及精确行格式或复杂示例，应回到来源章节核对。
