# LatticeConstant

## 含义
晶胞基矢的单位（由数值和单位构成），常用值为“1 Ang”，缺省值为“0.0 Bohr ”。“Ang”为埃（Å）， “Bohr”为玻尔单位（1 Bohr约等于0.52917725埃）。

## 默认值
0.0 Bohr

## 取值
非负实数；Ang/Bohr

## 何时使用
- 当使用 `3.1.3.3 LatticeConstant` 相关功能并需要设置 `LatticeConstant` 时。
