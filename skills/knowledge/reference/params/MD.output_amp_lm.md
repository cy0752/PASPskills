# MD.output_amp_lm

## 含义
MD的常用设置。用于设置是否输出MD模拟过程中的体系构型（包括原子位移和自旋方向），两次相邻输出之间的时间间隔由 MD.int_step 参数决定。

## 默认值
F

## 取值
T/F

这是布尔开关，不是输出间隔。两次相邻输出之间的步数由 `MD.int_step` 控制。

## 何时使用
- 当使用 `3.1.6 附属文件MD.input：分子动力学模拟相关设置` 相关功能并需要设置 `MD.output_amp_lm` 时。

## 注意事项
- 只能写 `T` 或 `F`。不要写 `50000`、`100` 这类整数；整数值表示输出间隔的理解是错误的
- 如果目标是降低输出频率，改 `MD.int_step`，不是改 `MD.output_amp_lm`
- 修改前应确认当前 workflow 阶段确实需要该设置，不要用参数调整掩盖结构或文件依赖错误。
- 若涉及精确行格式或复杂示例，应回到来源章节核对。
