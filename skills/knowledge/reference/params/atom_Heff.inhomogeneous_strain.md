# atom_Heff.inhomogeneous_strain

## 含义
是否开启局域的（非均匀）应变自由度。

## 默认值
F

## 取值
T/F

## 何时使用
- 当使用 `3.1.5.4 MC相关的其他设置` 相关功能并需要设置 `atom_Heff.inhomogeneous_strain` 时。

- 修改前应确认当前 workflow 阶段确实需要该设置，不要用参数调整掩盖结构或文件依赖错误。
