# atom_Heff.relax_str

## 含义
在“Model atomic_effective_H”中是否开启CG局域优化。

## 默认值
F

## 取值
T/F

## 何时使用
- 当使用 `3.1.5.5 CG局域优化的相关设置` 相关功能并需要设置 `atom_Heff.relax_str` 时。
