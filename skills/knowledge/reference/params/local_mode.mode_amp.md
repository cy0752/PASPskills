# block local_mode.mode_amp

## 含义
当“ local_mode.cal_para_method ”设置值为5时，可利用“block local_mode.mode_amp”生成自定义的构型，如案例所示。

## 默认值
对所有自由度全部赋0

## 取值
实数

## 何时使用
- 当使用 `3.1.7.7 随机生成构型或自定义构型的相关设置` 相关功能并需要设置 `block local_mode.mode_amp` 时。

## 注意事项
- 这是 block 类型设置，写入时必须使用 `%block ... %endblock` 结构，并保持 block 内格式完整。
- 若涉及精确行格式或复杂示例，应回到来源章节核对。
