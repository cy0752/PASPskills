# local_mode.nstr_random

## 含义
在“local_mode.cal_para_method”取1时，用于设置随机产生的构型数。在随机生成时，自旋自由度按模长为1随机生成方向，而局域声子模式和应变需要在“ block local_mode.mode_range ”所设置的取值范围内随机取值。需要注意的是，只有相互作用分析中考虑到应变相关项时才会在随机生成数据时产生随机的应变。

## 默认值
100

## 取值
非负整数

## 何时使用
- 当使用 `3.1.7.7 随机生成构型或自定义构型的相关设置` 相关功能并需要设置 `local_mode.nstr_random` 时。
