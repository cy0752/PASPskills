# nbeg_blk

## 含义
在一个大循环步骤中， nbeg_nlk 个交换步之后的数据用于进行热力学统计（包括能量、热容等统计量），注意 nbeg_nlk 取值不能超过 PT.nblk_T 。

## 默认值
0

## 取值
非负整数。

## 何时使用
- 当使用 `3.1.5.3 PTMC模拟步数与统计相关设置` 相关功能并需要设置 `nbeg_blk` 时。

## 注意事项
- 修改前应确认当前 workflow 阶段确实需要该设置，不要用参数调整掩盖结构或文件依赖错误。
- 若涉及精确行格式或复杂示例，应回到来源章节核对。
