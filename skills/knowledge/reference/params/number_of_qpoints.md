# number_of_qpoints

## 含义
PASP每次计算布里渊区1条线段上的自旋波色散，本设置项代表这条线段上q点的数量。

## 默认值
1

## 取值
正整数

## 何时使用
- 当使用 `3.1.11 线性自旋波色散计算常用设置项` 相关功能并需要设置 `number_of_qpoints` 时。

## 注意事项
- 修改前应确认当前 workflow 阶段确实需要该设置，不要用参数调整掩盖结构或文件依赖错误。
- 默认 `spinw` legacy 路径配合 `%block qpoints.magnon` 使用两行端点；线段计算应设置为至少 2。
- 多段路径不要把多段端点一次性塞进同一个 `qpoints.magnon` block；应分段运行或用脚本分段改端点并拼接输出。
- 若涉及精确行格式或复杂示例，应回到来源章节核对。
