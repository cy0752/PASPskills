# opt.EDIFFG

## 含义
CG精度设置，达到精度时自动结束CG优化。设置值为正时用相邻两步CG优化（对应两个不同优化方向）的能量变化小于设置值作为达到精度的条件，为负时要求所有自由度受力均小于设置值时作为达到精度的条件。

## 默认值
1.0E-5

## 取值
正或负实数

## 何时使用
- 当使用 `3.1.5.5 CG局域优化的相关设置` 相关功能并需要设置 `opt.EDIFFG` 时。
