# opt.NSW

## 含义
CG局域优化的最大步数。每一步CG需要相应地完成一次对尝试构型的能量估计（使用相应的有效哈密顿量模型）。

## 默认值
100

## 取值
非负整数

## 何时使用
- 当使用 `3.1.5.5 CG局域优化的相关设置` 相关功能并需要设置 `opt.NSW` 时。

## 注意事项
- 修改前应确认当前 workflow 阶段确实需要该设置，不要用参数调整掩盖结构或文件依赖错误。
- 若涉及精确行格式或复杂示例，应回到来源章节核对。
