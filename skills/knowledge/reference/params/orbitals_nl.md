# block orbitals_nl

## 含义
壳层信息，第一行为元素种类1，及其考虑的壳层数，下面每行列举所考虑壳层对应的主量子数及角量子数，再另起一行写元素种类2，及其考虑的壳层数，以及所考虑壳层对应的主量子数及角量子数。

## 默认值
无，不可缺省

## 取值
见描述

## 何时使用
- 当使用 `3.1.9 紧束缚模型方法常用设置项` 相关功能并需要设置 `block orbitals_nl` 时。

## 注意事项
- 这是 block 类型设置，写入时必须使用 `%block ... %endblock` 结构，并保持 block 内格式完整。
- 若涉及精确行格式或复杂示例，应回到来源章节核对。
