# 自旋诱导极化

## 目标
基于自旋构型、自旋-晶格耦合和统一极化模型，计算或分析自旋序诱导极化与相关磁电耦合现象。

## 适用问题
- 我想根据自旋构型计算极化
- 我想做 KNB / 统一极化模型
- 我想分析螺旋磁序诱导极化

## 输入前提
- `PASP.input`
- 与 KNB / GKNB 相关的模型输入
- 如涉及自旋-晶格项，还需相应耦合与力常数信息

## 典型阶段
1. 确认要分析的是纯电子贡献还是包含离子/应变贡献
2. 选择 KNB / 统一极化模型相关设置
3. 准备自旋构型、局域坐标和必要的耦合参数
4. 如涉及螺旋磁序，设置 `qvec` 与螺旋面方向
5. 运行极化计算并检查输出分量与坐标系一致性
