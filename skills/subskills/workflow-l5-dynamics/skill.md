## Responsibilities
- Identify the current stage of a dynamics simulation.
- Point out the next required inputs, controls, and output checks.
- Route detailed field questions to reference.

## Route To Reference When
- The user asks for a single `MD.input` field definition.
- The user asks about parameters such as `MD.Delta_t`, `LLG.method`, or `LLG.damping`.
- The user asks about files such as `Zeff.dat` or `elastic.dat`.
